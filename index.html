The one thing ACADBELL never does

When your timer runs out, nothing is marked complete for you. You review what you read and tick the topics yourself.

Built around how students actually study

Not another calendar app. Every screen exists to get you into a reading block and keep an honest record of it.

Reading timetable

Day, week and month views. Multiple sessions per day, each with its own start and end time, and weekly repeat patterns.

Alarms that actually ring

Start and end alarms fire even when the app is closed, after a reboot, and through timezone or clock changes.

Paste your topic list

Drop in a whole course outline. ACADBELL splits numbered lists, bullets and roman numerals into individual topics for you to review.

Live reading session

A countdown that survives you switching apps or locking your screen. Pause, resume, extend the block, or stop early.

Honest statistics

Actual hours read, completed and missed sessions, topics left, per-course percentages, streaks and consistency — all from real records.

Your data, on your phone

Everything stays in a local database. Export a backup file whenever you want. No cloud, no accounts, no tracking.

Never automated

Expiring the timer does not complete a topic

When allocated time ends, ACADBELL shows what you actually read and offers to move unfinished topics into a catch-up session. Only your tap marks a topic complete.

Install in four steps

ACADBELL isn't on the Play Store — it installs directly from this link. Takes about a minute.

1

Download the APK

Tap the download button. If Chrome warns about the file type, choose Download anyway.

2

Allow the install

Open the file and Android will ask to allow installs from this source. Allow it, then tap Install.

3

Enable alarms

Open ACADBELL, allow notifications, then in Settings enable exact alarms and the battery exemption.

4

Test it once

Tap Test in 60s and lock your screen. If the alarm rings, your phone is set up correctly.

Questions

Is it really free?

Yes. No ads, no subscription, no in-app purchases, no account. The app is open source and you can read every line of it.

Does it need internet?

No. ACADBELL doesn't even request the internet permission, so it cannot connect to anything. Everything — courses, topics, sessions, history — lives in a local database on your phone.

Why does my alarm arrive late or not at all?

Almost always one of two things: the exact-alarm permission is off, or the phone's battery manager is killing background apps. Brands like Tecno, Infinix, Xiaomi and Huawei do this aggressively. Open Settings → Alarm reliability in the app, allow exact alarms, exempt ACADBELL from battery optimisation, then tap Test in 60s to confirm.

Will my data survive a reboot or an app update?

Yes. Everything is stored in a local database that persists across restarts, reboots and updates. It's only lost if you uninstall the app or clear its data — so export a backup before you switch phones.

Can I move my data to a new phone?

Yes. Settings → Backup & data → Export writes a JSON file wherever you choose. On the new phone, install ACADBELL and use Restore.

Do I need to allow installs from unknown sources?

Android will ask, because the app is installed directly rather than through the Play Store. Android remembers the choice for this one file — you can revoke it afterwards in Settings.

Does it work on iPhone?

No. ACADBELL is a native Android app. iPhone users can't install it.
